The Challenge

Case information can become difficult to follow when official updates, media, and public discussion are scattered across separate channels. CaseAtlas explores a single platform where authoritative updates remain persistent while conversations and notifications can happen in real time.

My Role

I designed and built the full application flow across the web interface, API, authentication, media handling, data persistence, and real-time event layer.

What I Delivered

  • Case Tracking & Subscriptions: Subscribe to cases and stay informed.
  • Official Updates: Persistent, moderator-driven official updates for each case.
  • Media Uploads: Seamless image, video, and document uploads during case creation and updates.
  • Real-time Notifications: Instant alerts for new updates and interactions via Socket.io.
  • Modern UI: Fully responsive, accessible, and dynamic user interface.
  • Secure Authentication: Robust user authentication system.

Key Decisions

Separate official updates from discussion. Authoritative case information remains persistent and moderator-driven, while the conversation layer can stay fast and interactive without becoming the source of truth.

Use real time selectively. The API and database hold durable application state; Socket.io is used for notifications and live interactions where immediacy improves the experience.

Outcome

The live demo shows an end-to-end case-tracking workflow with authentication, persistent updates, subscriptions, media, and real-time interactions. The source is public for review.

Tech Stack

  • Frontend: Next.js (App Router), React, Next-Auth, Socket.io-client, Lucide React
  • Backend: Node.js, Express, Socket.io
