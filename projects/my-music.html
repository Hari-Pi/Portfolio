About the project

MY-MUSIC is a versatile collection of scripts built to download videos and audio from YouTube and popular social media platforms. Designed for simplicity, it allows everyday users to download media on Android via Termux without ads or malicious apps. Since it's built on Bash, it is fully compatible with any Linux system.

Key Features

  • Ad-free video and audio downloading
  • Support for YouTube and major social platforms
  • Optimized for Android via Termux
  • Cross-platform Linux compatibility
  • Lightweight, dependency-free bash execution

Tech Stack
