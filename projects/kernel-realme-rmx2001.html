About the project

This project features a specially modified Linux kernel for the Realme 6 (RMX2001). The primary goal is to establish compatibility with Droidian, effectively repurposing the smartphone into a powerful, cost-effective Linux server and a viable alternative to the Raspberry Pi.

Key Features

  • Droidian OS compatibility layer
  • Optimized for server workloads on mobile hardware
  • Cost-effective Raspberry Pi alternative
  • Custom driver implementations for RMX2001
  • Enhanced battery and thermal management for uptime
