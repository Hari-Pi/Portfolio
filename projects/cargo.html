About the project

The Cargo Management System is a comprehensive web-based application designed to streamline cargo shipments and deliveries. It offers dual portals: one for customers to book, track, and manage orders, and an administrative dashboard for overseeing shipments, generating invoices, and managing system users.

Key Features

  • Customer portal for booking and tracking shipments
  • Centralized Admin Dashboard for order oversight
  • Automated shipment invoice generation
  • Role-based access control (Customers, Admins)
  • Real-time cargo status tracking
