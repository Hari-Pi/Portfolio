The Goal

I built Next Anime Site as a focused way to learn how a media catalogue fits together in Next.js: discovery and search on the entry page, detail routes for individual titles, reusable recent-episode presentation, and a dedicated playback flow.

What I Built

  • Anime discovery: A browseable catalogue with search for finding titles quickly.
  • Detail routes: Dedicated pages that organize information for each anime.
  • Recent episodes: Reusable components for surfacing newly available content.
  • Media playback: A separate player route using HLS.js and Plyr for browser video controls.
  • Responsive interface: React components styled with Tailwind CSS across common screen sizes.

Engineering Focus

The project emphasized page-based routing, component boundaries, asynchronous data requests with Axios, and integrating streaming-media libraries into a React interface. It also provided practical experience structuring a typed Next.js application beyond a single-page demo.

Tech Stack

  • Application: Next.js 13, React 18, TypeScript
  • Interface: Tailwind CSS
  • Data and media: Axios, HLS.js, Plyr

Outcome

The result is an open-source learning project that demonstrates a complete media browsing path from discovery to title details and playback. The repository is kept available as a record of that Next.js exploration.
