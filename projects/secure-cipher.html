Secure-Cipher

A simple web app to encrypt and decrypt text, built with Next.js and DaisyUI.

Live Demo View on GitHub

About the Project

Secure-Cipher is a streamlined web utility designed for fast, reliable text encryption and decryption in the browser. Focused on privacy and ease of use, it allows users to securely mask sensitive information before transmitting it over insecure channels.

Key Features

  • Client-Side Processing: All cryptographic operations occur directly in the browser, ensuring sensitive data never leaves the user's device.
  • Instant Feedback: Real-time encryption and decryption as you type or paste.
  • Modern Interface: A clean, distraction-free UI built with DaisyUI for optimal user experience across devices.

Tech Stack

  • Frontend: Next.js, React, TypeScript
  • Styling: Tailwind CSS, DaisyUI
