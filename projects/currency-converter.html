About the project

Currency_Converter is a premium, feature-rich application built with Flutter. Designed for both casual users and frequent travelers, it offers a sleek, user-friendly interface to track real-time exchange rates, view historical currency data through interactive charts, and manage conversions efficiently—even offline.

Key Features

  • Real-time Conversion: Instantly convert between major world currencies using up-to-date rates from the Frankfurter API.
  • Interactive Charts: Visualize currency fluctuations over time with deep history tracking and interactive fl_charts.
  • Offline Support: Access previously fetched rates and continue converting without an active internet connection.
  • Custom Numpad & UI: Enjoy an optimized input experience and full support for system Dark/Light modes.
